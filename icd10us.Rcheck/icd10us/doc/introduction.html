Overview

The icd10us package provides comprehensive data and tools for working with ICD-10 codes in the United States healthcare context. It includes:

  • ICD-10-CM diagnosis codes with metadata
  • ICD-10-PCS procedure codes with metadata
  • Utility functions for transforming, filtering, and grouping codes

All datasets in this package are in the public domain, sourced from:

  • Centers for Medicare and Medicaid Services (CMS)
  • Centers for Disease Control and Prevention (CDC)
  • Healthcare Cost and Utilization Project (HCUP) from the Agency for Healthcare Research and Quality (AHRQ)

Each row represents one ICD-10-CM code with the following information:

  • icd10cm_code: The code itself (without dot)
  • icd10cm_short_description: Brief description
  • icd10cm_long_description: Full description
  • valid_billing_code: Whether the code can be used for billing (1=Yes, 0=No)
  • poa_exempt: Present on Admission (POA) exemption status
  • chronic_indicator: Classification as chronic (C) or acute (A) condition

Filtering Codes

You can filter the dataset using standard dplyr functions:

# Find all valid billing codes for diabetes
diabetes_codes <- icd10cm %>%
  filter(
    icd10cm_code >= "E08" & icd10cm_code <= "E13",
    valid_billing_code == 1

Code Validation and Formatting

Validating Code Format

The is_valid_icd10cm() function checks if a string matches ICD-10-CM format:

# Valid ICD-10-CM codes
is_valid_icd10cm("F320")    # TRUE
#> [1] TRUE
is_valid_icd10cm("E119")    # TRUE
#> [1] TRUE
is_valid_icd10cm("F32")     # TRUE
#> [1] TRUE

# Invalid codes
is_valid_icd10cm("296")     # FALSE - ICD-9 format
#> [1] FALSE
is_valid_icd10cm("F")       # FALSE - too short
#> [1] FALSE
is_valid_icd10cm("ABCD")    # FALSE - no numbers
#> [1] FALSE

Note: This only validates the format, not whether the code actually exists in the official code set.

Adding and Removing Dots

ICD-10 codes can be formatted with or without decimal points:

# Add dots
add_dot("F320")     # Returns "F32.0"
#> [1] "F32.0"
add_dot("E1165")    # Returns "E11.65"
#> [1] "E11.65"
add_dot("F32")      # Returns "F32" (3-char codes don't need dots)
#> [1] "F32"

# Remove dots
remove_dot("F32.0")   # Returns "F320"
#> [1] "F320"
remove_dot("E11.65")  # Returns "E1165"
#> [1] "E1165"
remove_dot("F32")     # Returns "F32" (no dot to remove)
#> [1] "F32"

Common Use Cases

Use Case 1: Identifying Chronic Conditions

# Create a function to identify chronic conditions in patient data
identify_chronic <- function(patient_codes) {
  patient_codes %>%
    left_join(
      icd10cm %>% select(icd10cm_code, chronic_indicator),
      by = "icd10cm_code"
    ) %>%
    filter(chronic_indicator == "C")
}

# Example with sample data
sample_patients <- sample_icd10cm(n = 50, p = 5)
chronic_diagnoses <- identify_chronic(sample_patients)

chronic_diagnoses %>%
  count(patient_id, sort = TRUE)
#> # A tibble: 0 × 2
#> # ℹ 2 variables: patient_id <int>, n <int>

Use Case 2: Grouping by Chapter

# Assign chapter to diagnosis codes
assign_chapter <- function(codes_df) {
  # Create a helper function to find chapter
  find_chapter <- function(code) {
    icd10cm_chapters %>%
      filter(code_start <= code & code_end >= code) %>%
      pull(chapter_desc) %>%
      first()
  }
  
  codes_df %>%
    rowwise() %>%
    mutate(chapter = find_chapter(icd10cm_code)) %>%
    ungroup()
}

# Example
sample_with_chapters <- assign_chapter(sample_icd10cm(n = 30, p = 5))

sample_with_chapters %>%
  count(chapter, sort = TRUE)

Data Provenance and Public Domain Status

All datasets in this package are derived from public domain sources:

ICD-10-CM Data Sources

  • Codes and Descriptions: CMS via CDC/NCHS
  • POA Exemptions: CDC/NCHS
  • Chronic Condition Indicators: AHRQ HCUP

ICD-10-PCS Data Sources

  • Codes and Descriptions: CMS
  • Procedure Classifications: AHRQ HCUP

These data are freely available and can be used without restriction for research, clinical, and commercial purposes.
